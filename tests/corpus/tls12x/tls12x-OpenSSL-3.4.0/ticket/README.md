# Векторы билета RFC 5077 (два рукопожатия подряд)

Издание: OpenSSL 3.4.0 22 Oct 2024 (Library: OpenSSL 3.4.0 22 Oct 2024)
Набор: ECDHE-ECDSA-AES128-GCM-SHA256, кривая X25519
full/    - первое рукопожатие, полное; в потоке сервера обязан быть NewSessionTicket (тип 4)
resumed/ - второе рукопожатие тем же билетом через -sess_in; обмена ключами и сертификата в нём нет
session.pem - билет, записанный клиентом через -sess_out
